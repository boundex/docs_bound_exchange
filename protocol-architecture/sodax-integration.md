# Sodax Integration

Bound's cross-chain swap functionality is powered by **SODAX** - enabling native asset swaps across BTC, ETH, SOL, and more without any bridging or wrapping.

## Key properties

* **Native assets** - no wrapped tokens at any point
* **No bridge** - assets don't pass through an intermediary protocol
* **Expanding** - new assets and chains added regularly

## Supported chains & assets

BTC · ETH · SOL · USDC · BNB · AVAX · HYPE · and expanding
